完成文献研讨报告的最佳流程：先用PyPDF2批量提取所有PDF核心内容（摘要、方法、结论）→ 按模板4部分结构组织内容 → 写generate_report.py生成docx。

**Why:** 研讨报告需要覆盖多篇论文（≥8篇才能拿高分），人工阅读效率低。批量提取PDF文本后，可以快速对比各方法的异同，组织出系统性的分析。分开生成脚本和报告内容便于迭代修改。

**How to apply:**
1. 先用PyPDF2提取每篇PDF前6页（通常包含摘要、引言、方法概述），输出3000字符即可抓住核心
2. 按4部分结构组织：工程问题需求分析 → 求解方法分析与比较 → 数据分析说明 → 研讨总结
3. 方法对比部分务必包含表格（方法/核心思想/LLM角色/优势/局限性），数据对比也用表格
4. 参考文献格式：[序号] 作者. 标题[期刊/会议]. 年份.
5. 研讨总结要包含：关键发现、挑战与不足、未来趋势、个人思考
6. 总字数6000-8000字为宜，参考文献≥8篇
